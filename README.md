# Arquitetura-em-Camadas

Este repositório contém um artigo sobre o modelo de arquitetura de software em camadas.

## Sobre

O artigo apresenta uma introdução ao conceito de arquitetura em camadas, explicando como esse modelo organiza sistemas de software em diferentes níveis, facilitando a manutenção, escalabilidade e separação de responsabilidades.

## Publicação

O artigo está disponível na aba **Wiki** deste repositório no GitHub.
